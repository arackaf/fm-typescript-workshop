# TypeScript in the Age of AI Course

This is a companion repo for the [TypeScript in the Age of AI course](https://master.dev/courses/typescript-ai/) from [Master.dev](https://master.dev). Master TypeScript and easily navigate complex AI-generated code. Learn advanced techniques like generics, conditional types, and discriminated unions, while gaining the skills to spot subtle mistakes and craft better prompts. Become the TypeScript expert on your team and take ownership over your type system.

## Course Format

Each module contains TypeScript examples for following along with the course. Some modules contain both exercises and solutions.
